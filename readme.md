# Мотиватор 🎯

Веб-приложение для мотивации школьников. Помогает детям ставить задачи, зарабатывать баллы и накопления за выполненные дела, а родителям — отслеживать прогресс.

## Возможности

✨ **Система задач** — предустановленные или собственные задания для выполнения:
- Домашнее задание
- Посещение тренировки
- Получение пятерки
- Чтение книги
- Уборка комнаты

💰 **Заработок и накопления** — зарабатывайте баллы и рубли за каждое выполненное дело:
- Настраиваемая ставка (баллов за задачу)
- Месячный лимит накоплений
- Отслеживание дневного результата

📊 **Прогресс и статистика** — видьте улучшения:
- Текущая серия выполнений
- Дневной результат
- Накопления за месяц
- Наглядные графики (Chart.js)

🔐 **Две роли** — разные интерфейсы для родителя и ребенка:
- Родитель: управление параметрами, просмотр статистики
- Ребенок: выполнение задач, заработок

## Технология

- **HTML5** — структура
- **CSS3** — адаптивный дизайн с переменными
- **JavaScript (Vanilla)** — логика приложения
- **LocalStorage** — локальное хранилище данных
- **Chart.js** — визуализация статистики
- **Google Fonts** — типографика (DM Sans, Manrope)

## Установка

1. Откройте `index.html` в браузере
2. Приложение готово к использованию

## Использование

### Для школьника
1. Откройте приложение
2. Переключитесь на роль "Ребенок" (кнопка ⇄)
3. Выполняйте задачи из списка
4. Зарабатывайте баллы и деньги
5. Отслеживайте прогресс

### Для родителя
1. Роль "Родитель" установлена по умолчанию
2. Настройте параметры:
   - **Ставка** — сколько рублей за каждый балл
   - **Лимит** — максимум накоплений в месяц
   - **ПИН** — пароль для защиты настроек
3. Добавляйте или редактируйте задачи
4. Просматривайте статистику дня и месяца
